# Дыхание · Пранаяма шаг за шагом

HTML-версия тренажёра дыхательных практик с программой постепенного усложнения и медалями.
Всё в одном файле `index.html` — откройте его в браузере (на телефоне или компьютере), сборка не нужна.

## Программа
1. **Квадратное дыхание** — 4-4-4-4 → 4-5-4-5 → 4-6-4-6 → 5-6-5-6 → 6-6-6-6
2. **Анулома-вилома** (вдох – задержка – выдох) — 4-0-4 → 4-0-8 → 4-4-8 → 4-8-8 → 5-10-10
3. **Капалабхати** (выдохов за раунд × темп) — 20×2 с → 30×2 с → 40×1,5 с → 50×1 с → 60×1 с

## Правила перехода
- Уровень = 7 дней практики; день засчитан, если завершена хотя бы одна полная сессия.
- Пропускать можно не больше 1 дня подряд (7 дней укладываются максимум в 14).
- Если правило нарушено — счётчик дней обнуляется, уровень сохраняется.

## Возможности
- Сессия по циклам (по умолчанию 3) или по времени с обратным отсчётом (по умолчанию 3 мин), звук фаз и сигнал окончания.
- Анимация дыхания, подсказки ноздрей для анулома-виломы, счёт выдохов для капалабхати.
- 13 медалей-достижений с нарисованными значками-животными.
- Раздел «Теория»: прана, зачем дышать, безопасность, описание техник, карта пранаям.
- Напоминания в браузере (работают, пока страница открыта).
- Прогресс хранится в localStorage этого браузера.
